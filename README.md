# E-CUP 2026: Контроль качества

Решение задачи проверки карточек товаров из категорий БАД и легковоспламеняющихся товаров.

Описание задачи: https://ods.ai/competitions/e-cup-2026-quality

## Запуск

```bash
python submit/run.py -i test.csv -o submit.csv
```

Текстовые признаки TF-IDF используются с логистической регрессией.
Для БАД применяется NB-взвешивание, для ЛВ объединяются два текстовых канала.
Обучающие данные находятся в `submit/train_data.csv`.
На выходе CSV со столбцами `id` и `result` в формате соревнования.
