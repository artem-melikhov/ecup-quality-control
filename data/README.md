# Данные

`raw/train_data.csv` содержит исходные карточки и метки. Этот файл используется для обучения при каждом запуске.

В `processed/` лежат готовые данные:

| Файл | Для чего нужен |
|---|---|
| `train_ocr.csv` | Распознанные надписи на обучающих фотографиях по ID товара |
| `train_vision.npz` | Признаки CLIP, ID товаров, маска доступных фото и подпись модели |
| `lv_groups.json` | Группы почти-дублей для отбора примеров ЛВ |
| `fewshot_examples.json` | Фиксированные примеры для промптов по подкатегориям |

Исходные фотографии хранятся отдельно. Их путь задаётся при подготовке данных или в `configs/local.json`.

Состав подготовленного набора и контрольные суммы находятся в [reports/preparation.json](../reports/preparation.json).
