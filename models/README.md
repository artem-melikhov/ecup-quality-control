# Локальные веса

В этой папке хранятся веса, которые не загружаются в Git:

- `clip/` содержит CLIP ViT-B/32 для визуального классификатора.
- `tessdata/` может содержать языковые данные Tesseract для локального запуска.

Команды скачивания и подготовки описаны в [README](../README.md#подготовка-clip). При сборке отправки содержимое `clip/` включается в ZIP. Языковые данные Tesseract устанавливаются в Docker-образ.

Gemma и Qwen по умолчанию читаются из `/shared_models`. Этот путь меняется через `SHARED_MODELS_PATH`.
